The same stock trades in many pools on X Layer. Some can fill a $1,000 order for a few cents; others would charge more than the order is worth. Every minute StockGuard reads each pool on-chain, checks it against an independent price, and lets a 16-gate NAND circuit decide: ROUTE_OK, CAUTION or DO_NOT_ROUTE.

CAUTION      = ¬DO_NOT_ROUTE ∧ (GAP ∨ CLOSED)
ROUTE_OK     = neither · could not evaluate = DO_NOT_ROUTE (fail closed)

    How a verdict is made

    Real pools onlyUniswap v3 pools are kept only if the official factory confirms them (factory.getPool). Token details are read from the token contracts, not from a listing.
    Depth from a real quoteThe $1,000 cost comes from Uniswap's QuoterV2 on X Layer: fee and every price step included. Over 1% → THIN.
    An independent priceThe same token on another chain, the Coinbase NAV, or the original xStock elsewhere. Off by ≥ 2% → GAP; twice in a row → CONFIRMED. No reference at all → STALE.
    Trusted dollarsStablecoins are pinned by address (USDG, USDC). Stock-for-stock pools are priced through the other stock's own healthy pool, on-chain.
